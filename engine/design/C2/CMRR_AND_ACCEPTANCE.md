## Current status and limits

The text defines the common lifecycle, ordinary-action effects, actual dependency requirements, durable recovery, timeline boundaries, autonomous institutional scope and implementation order. Existing Core runtime behaviour remains as recorded in its source and historical evidence. No source in the active live suite or website was replaced by this work.

Before the user's text-first clarification, an isolated coding draft was started under `IRGS_3_3_C`. It contains partial workflow, storage, CLI and test experiments. Coding stopped at the clarification. A storage-only component run had passed locally, but the workflow and distribution were not integrated or accepted. The entire draft folder is excluded from this package; its presence must not be represented as a live 3.3.C engine.

This handoff does not establish a general resolved first turn, a completed Living Day, calibrated historical economics, universal NPC agency, live calendar execution, automatic epoch summaries or full genre qualification. These require implementation and the named evidence gates. New campaign templates, historical rates and numerical genre rules still require their own source and adoption decisions.
