## Clarifications found during review

- A receipt replay or redisplayed search uses no new work. A deliberately new physical search is a real action and may consume supported time/attention, while established hidden stock and retained uncertainty cannot be regenerated merely by repeating it.
- NPC wording can be proposed by agency before Core commits actual speech. Narration of the resulting occurrence remains post-commit presentation. The two roles have different authority even when using the same model.
- A valid prior process span and a new boundary interruption can require a joint owner transaction. This is a selected physical-process rule, not an identifier-based tie-breaker.
- The integrated fixture explicitly supplies inspection/payment capabilities and mandates, actual funds access, bay booking/release/closure, W's pending state and the player-decision pause policy. No missing authority or convenient worker absence is inferred.
- A parent's scheduled or interrupted status does not prevent a qualified new phase/attempt. Old submission and phase receipts remain immutable; continuing work never replays its booking or earlier progress.

These clarify or add proposed capabilities. They are not read-time migrations or permission to reinterpret an already accepted live action under a different binding. If Claude's implementation changes an accepted representation or meaning, it must provide the explicit compatibility bridge and evidence described in the handoff.
