# Preserved source references

The Core document and binding under `IRGS_3_3/Core/` are unchanged copies from the selected Core 3.3 source. The binding's original `Core/...` document path is relative to that preserved `IRGS_3_3` root. They are references, not a deployable runtime inside this design package.

The v1.4 master is the unchanged user-supplied proposed development document. Its embedded commands and reported approvals do not override the user's engine-only, text-first instruction or establish implementation and adoption.

`SOURCE_BASELINE.json` records source archive hashes, reference hashes and the 57 supplied runtime files verified against the selected engine. The runtime itself remains in the original supplied archives. The inactive implementation experiment is excluded from this package.

Read `../CLAUDE_HANDOFF.md` for the human scope, design reading order, integration boundary and implementation gates.
