# IRGS Military Library v1.0 — Validation Summary

**Result:** 76 checks before adding this validation report to the manifest; 77 checks on the completed release (including its manifest hash verification).

Verified: original 6 era tags and 12 categories; 72 distinct source-qualified era/category cells; 48 unique proposed template definitions; 60 sequential acceptance *specifications*; exact SCL exemplars against normative registry at creation; retained historical source files and all 30 original Soldier/Military acceptance requirements in provenance; five bounded synthetic checks of stock transfer/duplication, item issue/custody, weapon modes, casualty reporting and qualification. Full archive checksums are in `PACKAGE_MANIFEST.json`.

**Limitations:** The 60 proposed behavior cases have not been run in a complete IRGS runtime. The source ML-0.1 is an equipment/era index; no historical regional accuracy or specific item numerical performance is certified. The Soldier/Military Slim v1.0 still pins Core 3.0 and SCL 0.1; this package does not constitute or certify a complete Core 3.2 bridge. This library remains a proposed replacement for the previous *Military Equipment and Technology Library* index, not an adopted campaign migration. Source SCL registry is not embedded as a normative duplicate.
