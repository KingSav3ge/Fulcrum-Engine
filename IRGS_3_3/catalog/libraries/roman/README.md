# IRGS Roman Republic Content Library v1.0 (Candidate)

**Best starting document:** `IRGS_Roman_Republic_Content_Library_v1_0_Candidate.md`.

This catalogue is a **proposed setting-specific content extension**, not a replacement for the finalized Roman Republic Slim v1.2 engine. It inherits Core v3.2 and SCL v1.0, preserving each SCL `@0.2` immutable family reference and the original 14 Roman local effect/profile bindings.

Contents:
- Main readable Roman catalogue with 118 individually qualified proposed setting templates.
- JSON/CSV catalogue, 14-item exact source-native SCL crosswalk.
- 20 full-engine + 12 slim-section CMRR disposition matrix.
- 64 specified acceptance requirements (not claimed tested in a live runtime).
- 29 dated/legal/physical calibration gates.
- Source snapshots (Roman Slim v1.2, full Roman v1.0 and native v1.2 binding JSON), CMRR report, verification instructions, and SHA-256 manifest.

**Binding gate:** date/place/role/authorization + full source payload or selected adapter + usable physical configuration/legality + actual Core instance. Catalogue existence never creates items or world state.

To verify: `python tests/verify_roman_content_release.py <extracted-package-path>`.

**Status:** Proposed, not independently historical-calibrated, engine runtime-tested, live-playtested or adopted into any campaign.
