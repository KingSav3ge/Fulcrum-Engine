# IRGS Core 3.3 live local suite

Double-click `Start-IRGS-3.3.cmd` whenever you want to play. It starts IRGS in the background and opens http://127.0.0.1:8765, or reuses the running website. Codex need not be open. Keep `IRGS_3_3` beside `IRGS_Web`.

Core 3.3 supplies the shared kernel. Six genre engines, eight technical libraries and seven installed profile adapters remain available internally. The player Content Library lists The Hundred Years’ War. A Scot’s Tale is a named 1415 starting reference; its reusable mechanics belong to shared Core/genre handlers, and its legacy adapter is archived.

Read `SUITE_RELEASE.md` for exact capabilities and limits, `CMRR_3_3_Release.md` for reconciliation, and `results/completion_audit.json` for evidence. Existing campaign files are preserved, and library lookup advances no game state.

Select a campaign and choose **Delete campaign** to move it to recoverable Trash. Use **Campaign Trash** to restore its complete save.

The Content Library offers **The Hundred Years’ War**: ten featured years, all 37 supplied dates, and a developed 1415 opening. Other dates remain proposals. Later history is not scripted.

Solo setup proceeds from campaign and entry through scenario, character and review before saving. Story, World and Chronicle share the same saved world. Historical selections have sourced briefings; date-aware faction and character availability follow the actual playthrough after initialization. Optional origin, family and career drafts are received player testimony, not automatic jobs, skills or resources. The historical comparison is read-only and never executes a future event. Freeform declarations are saved exactly; general narration and automatic calendar advancement are not implemented. Creator tools require explicit mode selection. Co-Op remains deferred.
